# 🎭 AI长篇小说生成器

一个功能强大的交互式长篇小说生成器，支持OpenAI兼容接口，让创作变得简单而有趣。

## ✨ 主要特性

- 🎨 **可视化界面** - 现代化的Web UI，操作简单直观
- 🤖 **OpenAI兼容** - 支持任何OpenAI兼容的API提供商
- 📖 **一键生成** - 可以一次性生成多个章节，也可以逐章创作
- 🌍 **世界观管理** - 自动生成完整的世界观、角色、时间线设定
- 🎮 **交互式创作** - 游戏对话式的剧情控制体验
- 💾 **存档系统** - 随时保存和加载创作进度
- 🎯 **剧情建议** - AI智能提供多个剧情走向选择
- 📊 **网文品质** - 专业的提示词工程，生成符合热门网文标准的内容

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动服务

```bash
npm start
```

服务将在 `http://localhost:3000` 启动

### 首次使用

1. **添加API提供商**
   - 点击"添加提供商"按钮
   - 填写提供商名称（如：OpenAI、DeepSeek等）
   - 填写Base URL（如：https://api.openai.com）
   - 填写API Key
   - 点击"获取模型"按钮加载可用模型

2. **创建新小说**
   - 填写小说名称
   - 输入一句话创意（如：一个现代程序员穿越到修仙世界）
   - 选择小说类型（玄幻、都市、科幻等）
   - 选择要使用的AI模型
   - 设置总章节数

3. **初始化设定**
   - 点击"初始化小说设定"按钮
   - AI会自动生成完整的世界观、角色、地点、时间线等设定
   - 在"世界观设定"标签页查看生成的内容

4. **生成章节**
   - **逐章生成**：点击"生成下一章"按钮
   - **一键生成**：点击"一键生成所有章节"按钮

5. **交互式创作**
   - 切换到"交互式创作"标签页
   - 与AI对话，讨论剧情走向
   - 查看AI提供的剧情建议
   - 根据建议调整后续章节

6. **保存和加载**
   - 点击"保存当前小说"保存进度
   - 点击"加载存档"恢复之前的创作

## 📋 功能说明

### 模型配置

支持任何OpenAI兼容的API接口：
- OpenAI
- Azure OpenAI
- DeepSeek
- 智谱AI (GLM)
- 百川
- 通义千问
- 任何实现OpenAI接口标准的服务

### 世界观管理

自动生成并管理：
- **世界观设定** - 背景、历史、文化
- **角色设定** - 主角、配角、反派的详细描述
- **地点设定** - 重要场景和地点
- **时间线** - 过去、现在、未来的重要事件
- **力量体系** - 修炼/魔法/科技等体系
- **等级体系** - 清晰的实力划分

### 章节生成

- 每章至少2000字
- 自动生成章节标题
- 包含剧情概要和关键点
- 保持前后连贯性
- 符合类型特色

### 交互式创作

- 与AI讨论剧情发展
- 获得多个剧情走向建议
- 随时调整创作方向
- 保持创作的灵活性

### 存档系统

- 自动保存所有设定和章节
- 支持多个项目并行创作
- 随时恢复任意存档
- 导出功能（复制章节内容）

## 🛠️ 技术栈

- **后端**: Node.js + Express
- **前端**: 原生 HTML/CSS/JavaScript
- **AI接口**: OpenAI兼容接口
- **数据存储**: 本地JSON文件

## 📝 使用技巧

1. **提高生成质量**
   - 使用更强大的模型（如GPT-4）
   - 提供更详细的创意描述
   - 在交互模式下给予更多指导

2. **控制剧情走向**
   - 利用交互式创作功能
   - 选择AI提供的剧情建议
   - 在生成前通过对话明确方向

3. **优化创作流程**
   - 先初始化设定，确保世界观完整
   - 分批生成章节，边生成边调整
   - 定期保存进度

4. **处理不满意的内容**
   - 使用"重新生成当前章"功能
   - 在交互模式下提出修改意见
   - 调整temperature参数（需修改代码）

## 🔧 配置说明

```bash
PORT=3000  # 服务端口，默认3000
```
